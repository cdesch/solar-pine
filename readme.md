# Solar Pine

A Kiro Crew dashboard theme. It keeps Solar's cream text and status colors and replaces the blue-teal base with deep pine green. It includes dark and light modes.

## Install

In Kiro Crew, open Settings -> Display -> Install theme and enter the repo URL:

```
https://github.com/cdesch/solar-pine
```

Then select "Solar Pine" and switch between dark and light with the topbar button.

Files: `theme.json` (manifest) and `variables.json` (dark and light palettes) sit at the repo root, which the installer requires.

## Palette

| Role | Dark | Light |
|---|---|---|
| Background | `#06241d` | `#f6f3e0` |
| Card | `#0b3329` | `#ffffff` |
| Text | `#9fb5a8` | `#3f5f52` |
| Strong text | `#eee8d5` | `#0b3329` |
| Accent | `#6fd6a0` | `#1b6b4a` |
| Info | `#2aa198` | `#1f7f78` |

Status colors (ok, warn, danger, aim) are unchanged from Solar.

## Based on

The variable set comes from the built-in `solar-dark` and `solar-light` themes. Solar is by Ethan Schoonover (MIT).
