# Solar Pine

A Kiro Crew dashboard theme. It keeps Solar's cream text and status colors and replaces the blue-teal base with deep pine green. It includes dark and light modes.

## Install

1. Open the Kiro Crew dashboard and go to the theme picker.
2. Choose the custom theme editor and click "Paste JSON".
3. Paste the contents of [`themes/solar-pine.json`](themes/solar-pine.json) and save.
4. Select "Solar Pine" and switch between dark and light with the topbar button.

## Palette

| Role | Dark | Light |
|---|---|---|
| Background | `#06241d` | `#f6f3e0` |
| Card | `#0b3329` | `#ffffff` |
| Text | `#9fb5a8` | `#3f5f52` |
| Strong text | `#eee8d5` | `#0b3329` |
| Accent | `#6fd6a0` | `#1b6b4a` |
| Info | `#2aa198` | `#1f7f78` |

Status colors (ok, warn, danger, aim) are unchanged from Solar.

## Based on

The variable set comes from the built-in `solar-dark` and `solar-light` themes. Solar is by Ethan Schoonover (MIT).
